## 写入约定

- **改代码 → 必写 `修改内容.md`**:在文件顶部(在 `---` 分隔线下)追加新章节,日期 + 分支名 + 表格化的改动列表 + 风险评估
- **新知识 → 写到 `note.md`**:分类用 `>` 引用块(已有 ajax readyState、组件问题、Hook、Redux、Canvas vs SVG、生命周期等分类)
- **不要在 `update-log*.md` 里再写内容**:它们已经"冻住",只读
